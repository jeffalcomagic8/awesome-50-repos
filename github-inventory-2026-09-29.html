04 / ai pm workflow

From problem to proof, six repos

Run in order. Each step's output feeds the next. Commands come from the source guide; check each README before installing.

01 / discovery

PM Skills

Plugin marketplace for Claude Code and Cowork. Run /discover on real interview notes, tickets, and usage data.

claude plugin marketplace add phuryn/pm-skills
claude plugin install pm-product-discovery@pm-skillsOut: problem statement
02 / prd

Product-Manager-Skills

PM skills as plain Markdown. The PRD skill walks the document section by section.

git clone https://github.com/deanpeters/Product-Manager-Skills.git
claude "Using skills/prd-development/SKILL.md, create a PRD for <feature>"Out: PRD draft
03 / specs

Spec Kit

GitHub's spec-driven toolkit. Needs Python 3.11+ and uv. Specify, clarify, plan, then tasks.

uv tool install specify-cli
specify init my-project --integration <agent>Out: spec + plan + tasks
04 / tasks

Task Master

Lighter than Spec Kit when the PRD exists. Vague tasks usually point to gaps in the PRD.

npm install -g task-master-ai
task-master parse-prd .taskmaster/docs/prd.txtOut: task list
05 / prototype

bolt.diy

Open-source Bolt.new. Prompt one user story, bring your own LLM key. Feedback only, not production. Low activity since Feb 2026.

git clone -b stable https://github.com/stackblitz-labs/bolt.diy.git
cd bolt.diy && pnpm install && pnpm run devOut: clickable prototype
06 / evaluate

promptfoo

Test prompts and models side by side against your cases and red-team for prompt injection. Rerun on every change.

npx promptfoo@latest init
npx promptfoo@latest evalOut: eval report
